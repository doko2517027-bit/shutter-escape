# Switch & Shutter / Test build 01

独立した新規プロジェクト。旧Panzer / NurseQuestのコード・認証・データは再利用していません。CareMateを変更しません。

## 遊ぶ

公開テスト版: https://shutter-escape-test.onrender.com

スマートフォン・PCとも横画面専用です。縦向きでは回転案内を表示し、プレイを開始しません。対応するスマートフォンでは全画面開始時に横向きロックを試みます。iPhone等でブラウザがロックに対応しない場合は、端末を横に回してください。

PC: WASD移動、マウスで視点、Spaceジャンプ、Eで調べる、Escでメニュー。画面に入る操作でマウスを固定します。ブラウザが固定を拒否する場合はマウスドラッグによる視点操作へ切り替わります。スマートフォンでは左スティック・右ドラッグ・ジャンプ/調べるボタン。ダッシュ・マップ・アイテム・成長・三人称切替はありません。

「ゲーム開始」でゲスト・ログイン・新規登録を選び、その後ソロまたはフレンド協力を選びます。登録済みアカウントは「このアカウントで続ける」で進めます。最大4人。全員が準備完了したらホストが開始。招待リンクか6文字コードを共有します。参加人数と同じ数の怪物が出現します。捕獲された本人のみ脱落し、他の参加者は続行できます。ホストのリスタートは全員をリセットします。

無料Renderの初回アクセスではサーバー起動を待つ場合があります。ルームはメモリ上に保持し、再デプロイ・サーバー再起動で消えます。切断後30秒は同じタブから再接続を試みます。切断中もゲームは進行し、水上では捕獲される場合があります。招待コードを知る人が参加できる匿名テスト版です。

## 操作の調整（2026-10-25）

- 添付されたアイコンを加工せず、favicon・Appleタッチアイコン・Webアプリのmanifestへ設定。
- 歩行速度4.6は維持。怪物の標準追跡速度24、水音を聞いた際に即座に経路を更新。
- ジャンプテンポ1.2。離陸・落下・空中移動を合わせて速め、元の高さと飛距離を大きく変えずに滞空を短縮。
- 移動・視点・ジャンプを個別のPointer IDで処理。タッチのジャンプは押した瞬間に1回発生し、離した時の重複クリックは無視。
- アプリ内のピンチ、タッチのダブルタップ、トラックパッドのピンチ相当操作を抑止。メニューのパン/スクロールとOSの拡大機能・キーボード操作は維持。
- ステージ開始・リトライごとにランダムな足場ルートを生成し、協力時はサーバーが決めたシードを全員で共有。再接続では同じ配置を復元。足場ごとの位置・幅・奥行きも不均等にし、狭い隙間と端からのジャンプが必要な隙間を混在。初期値で端近くの踏み切りなら届く一方、早すぎるジャンプでは届かないことをテスト。初期足場は4人が立てる広さを維持。
- ゲーム開始後にゲスト・ログイン・新規登録を明示。ゲスト選択でログアウトしてもアカウントは削除しません。素材管理の本人確認は維持。

## 開発

Node.js 22以上。`npm ci` → `npm run server`（3107）と `npm run dev`（5173）を別端末で起動。`npm test`、`npm run build`。本番は`npm start`がdistとWebSocket `/socket`を同一ポートで配信します。健康確認`/api/health`。

- `shared/world.js`: 名称・ステージ・レバー・衝突形状・パラメータ範囲・水上経路探索
- `shared/engine.js`: 共通の30Hz移動・ジャンプ・水音・怪物AI・勝敗処理
- `server/index.js`: サーバー権威型のルームと入力検証。30Hz処理/15Hz配信
- `src/main.js`: 画面・操作・クライアント予測・未確認入力の再適用・他プレイヤー補間
- `src/scene.js`: Three.js表示・仮素材・素材配置・演出
- `src/assets.js`: IndexedDB保存・形式検証・素材パック
- `src/audio.js`: 仮のWebAudio環境音とSE
- `test/`: ルール・実移動による全レバー/出口到達・GLB検証・実ソケットの協力/再接続

`PORT`はホストが指定可能。`ALLOWED_ORIGINS`は許可するWebSocket Originのカンマ区切り（未設定は匿名テストとして許可）。別のサーバーを使用するフロントは`VITE_SERVER_URL`をビルド時に設定します。Sitesの私用プレビューは上記Renderに接続します。

## アカウントと管理者

タイトルの「ログイン / 新規登録」からメールとパスワードで登録できます。パスワードは本人が入力し、Firebase Authenticationが管理します。登録後に確認メールのリンクを開き、「メール確認・権限を再確認」を押します。パスワード再設定・確認メール再送・ログアウトにも対応。登録なしのプレイは継続できます。

素材管理ボタンは管理者本人のログイン時のみ表示します。管理者はサーバー環境変数`ADMIN_EMAIL`に指定したメールと、Firebaseで確認済みの本人であることの両方が条件です。許可メールは公開コードやフロント設定へ書きません。ゲーム専用Firebaseプロジェクトは`switch-shutter-20261024`。`public/firebase-config.json`は公開Web設定（管理者資格や秘密鍵ではありません）です。

サーバーは署名・プロジェクト・発行元・有効期限を検証し、Firebaseの最新ユーザー情報でもメール確認・無効化・失効を確認します。ブラウザが送る`admin`等の役職指定は採用しません。管理画面を開く時と各管理操作の前に`/api/admin/access`で再検証します。管理者の登録・メール確認は本人が行う必要があります。

素材はゲーム専用Firestoreへ共有保存します。更新権限は非公開の `internal/assetAdmin` に登録した管理者UIDとメール確認済みの本人に限定し、ゲストは公開済み素材だけを閲覧できます。ブラウザ側の役職指定だけでは変更できません。

## 素材を差し替える

管理者ログイン後、タイトル画面の **素材管理** → **差し替え対象** → **画像 / GLBを選択** → 必要なら相対位置/回転/スケールを調整 → **保存して全員に反映**。デフォルトボタンで対象だけ元に戻せます。ゲーム名も同じ画面で変更・保存できます。

| 対象 | 形式 | 反映先 |
| --- | --- | --- |
| 背景画像 | PNG/WebP/JPG | 3Dシーン背景 |
| ステージ装飾 | GLB | 固定衝突ステージに追加する装飾 |
| 怪物 | GLB/画像 | 全怪物の仮モデル置換 |
| ゴール扉 | GLB/画像 | シャッターの表示と開閉 |
| レバー | GLB/画像 | 3か所のレバー表示 |
| レンガ表面 | PNG/WebP/JPG | 全足場のテクスチャ |
| 水面 | PNG/WebP/JPG | 水面素材 |
| ゲームUI | PNG/WebP/JPG | プレイ画面の画像レイヤー |
| タイトルロゴ | PNG/WebP/JPG | タイトル文字の代わりの画像 |
| プレイヤー手元 | GLB/画像 | カメラに追従する手元素材 |

位置/回転/スケールは3D配置対象に適用。背景・テクスチャ・ロゴ・UIは自動配置です。GLBは表示上の高さに正規化してから相対変換を適用します。1ファイル16MB、画像各辺4096pxまで。GLB 2.0の埋め込みデータのみ対応、外部参照・Draco/Meshopt圧縮は非対応です。アニメーションGLBのスキニングは表示できますが、歩行アニメーション再生制御は未実装です。

**保存後は全プレイヤーへ反映します。** Firestoreの公開マニフェストを購読し、別端末・別URL・協力相手にも自動配信します。画像・GLBは16MBまで、384KiBずつ分割保存し、全データの保存完了後に公開先を切り替えます。SHA-256で読み込みの完全性を確認し、途中失敗時は前の公開モデルを維持します。直前のモデルを保持し、それより古いモデルは更新後に削除します。サーバー再起動や再デプロイで素材は消えません。

旧バージョンでこのブラウザに保存済みの怪物GLBは、同じブラウザで管理者ログイン後に開くと、共有先にまだ怪物がない場合だけ自動移行します。「この端末のみ（未共有）」の他素材は対象を選び「保存して全員に反映」を押してください。素材パックはバックアップ・共有保存への復元にも利用できます。複数素材のパック復元は素材ごとの公開切り替えです。

**モデル変更でゲームの衝突形状は変わりません。** worldは装飾用、brickは表面素材です。大きな形状変更にはshared/world.jsで物理ステージも変更・再検証する必要があります。視覚素材と安全地帯を異なる形にしないでください。見た目の共有は実装済みですが、衝突形状の管理画面編集は未対応です。

## 調整

「設定」でBGM/SE音量（0で消音）、視点感度、FOV 55〜85°、画質、モーション軽減を保存。「ゲーム調整パラメータ」を開くと移動速度、ジャンプ力、ジャンプの速さ、重力、加速、減速、怪物速度、反応距離、音の記憶時間、捕獲時の個人/全員脱落を変更できます。次のゲーム開始時に適用し、協力はホスト設定を使用。最大ジャンプ距離の目安も表示します。極端な調整ではジャンプが届かなくなるため、初期値での通しテストを基準にしています。モーションブラーは使用しません。

## テスト・残作業

仮の3D形状・レンガテクスチャ・水面シェーダー・合成音を使用。初期値で全レバーと出口へ移動/ジャンプだけで到達できる自動テストを含みます。スイッチ・扉・怪物・報酬等のダミーボタンはありません。医療/旧ゲームデータはありません。

本番版には正式モデルと音源、複数実機のFPS・マルチタッチ確認、長時間/悪条件通信テスト、常時稼働ホスト、永続ルーム/監視/負荷対策、アクセシビリティの追加レビューが必要です。無料ホストのスリープや全端末の滑らかさは保証しません。テスト版の終了ボタンはブラウザを強制終了せずタイトルへ戻ります。

ランダム配置は1,000種類を生成検証し、500種類について実際の移動・ジャンプ計算で全レバーと出口への到達を検証。

## 感度と見た目の管理
- プレイ中は右上「感度」（PCはOキーでも開閉）、一時停止画面にも感度スライダー。変更直後に反映され、端末に自動保存します。マウス・スライドの両方に適用。
- 管理者でログイン → 素材管理 → 差し替え対象。水面、床・足場、外壁・内壁、水底、天井梁・柱・扉枠、配管、照明器具、怪物、協力プレイヤー、ゴール扉、レバー、手元、波紋、背景、装飾、UI、ロゴを個別管理。
- 表面には画像、立体物には画像またはGLB。保存して反映、対象別の色・透明度・材質・画像繰り返し設定、初期化に対応。画像専用項目では適用できる設定だけ表示します。
- 全体設定で霧の色・濃さ、画面と周囲照明の明るさ、手元ライト、水面アニメーション速度を保存・初期化。
- 素材と見え方は共有保存し、全利用者へ反映します。素材パックに設定も含めて持ち出し・復元可能。音量・視点感度など個人の設定は端末別のままです。衝突・ジャンプ・ランダム配置・敵の判定は変更しません。

## 怪物との接触
標準モデルの身体幅とプレイヤーの幅を合わせて判定し、怪物の経路の各区間で移動途中の接触も確認します。水面上の低いジャンプ中も身体が重なれば捕獲されます。足場の上・その真上は安全で、壁や足場の側面越しには捕獲しません。水音の経路は最後のグリッド位置から実際の音源へ近づき、水際で不自然に手前停止しないようにします。ソロ・協力とも同じサーバー権威型の判定を使います。

## 共有素材の運用
- Firebase `switch-shutter-20261024` / Firestore `(default)`（asia-northeast1、Standard、無料枠、課金未有効化）。Firebase Storageの有料プランへの変更は行いません。
- `sharedAssets`: 公開中の素材バージョン・変換・見え方。`assetUploads/{id}/chunks`: GLB/画像の分割本体。未公開データは管理者以外閲覧不可。`internal/assetAdmin`: 非公開の管理者UID。
- `firebase deploy --only firestore --project switch-shutter-20261024` でルールとインデックスを反映。既存アカウント・ゲームルール・CareMateを変更しません。
- 無料枠には保存・読み書き・転送量の上限があります。端末には公開バージョン単位でキャッシュし、同じモデルを毎回ダウンロードしません。大規模配信へ進む際はオブジェクトストレージ/CDNへの移行を検討します。課金変更は別途確認が必要です。
- 検証用は `firebase emulators:start --only firestore --project demo-shutter-assets`、別端末で `FIRESTORE_EMULATOR_HOST=127.0.0.1:8189 node --test test/shared-firestore.test.js`。本番の素材にテストファイルは公開しません。
